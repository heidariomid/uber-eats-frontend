# Stack

Next.js overlay from the process kit. Where **This repo** disagrees
with the overlay below, **This repo** wins.

## This repo

- Package manager is npm. The repo already has a lockfile
- This branch is the Next.js app. Commands:

```bash
npm run dev
npm run build
npx next start -p 3000   # the API's CORS allows only localhost:3000
npm run lint
npx tsc --noEmit
npm run graphql:gen
```

- The API is `../uber-eats`, NestJS, on `http://localhost:4000/graphql`
  with `graphql-ws` on the same path. Start it with
  `npm run start:dev` in that repo before any QA
- `src/graphql/schemaTypes.ts` is generated by codegen from the
  running API. Never hand-edit it
- Every page is a client component. The token lives in
  `localStorage`. Server rendering never reads `localStorage` or
  `window`. No server-side data fetching. The overlay's "server
  components by default" and "server actions for forms" do not apply
- State: `redux-saga` on a Redux Toolkit store, read through
  `StateProvider`. Do not replace it
- Public env from spec 3: `NEXT_PUBLIC_GRAPHQL_URL`,
  `NEXT_PUBLIC_GRAPHQL_WS_URL`. Nothing else is read
- Images: `next/image` only for new code. Do not convert every
  existing `<img>` in an upgrade spec
- Do not push. Do not deploy. Do not change the Vercel project

## Docs rule

This is not the Next.js in training data. Read
`node_modules/next/dist/docs/` before writing App Router, metadata,
or cache code.

## Shape

- App Router. Routes in `src/app/`
- `'use client'` for interactivity, hooks, or browser APIs
- Static where possible
- `next/image` for every new image

## Data

- Only `NEXT_PUBLIC_*` reaches the browser
- Generated types, never a hand-written copy of a GraphQL type

## Styling

If Tailwind v4 (spec 4 on): no `tailwind.config.*`. Tokens under
`@theme` in `globals.css`. Pin the source or a stray file can produce
zero utilities while base styles still apply:

```css
@import 'tailwindcss' source(none);
@source "../**/*.{js,jsx,ts,tsx}";
```

Dynamic class names must appear as full literals in a scanned file.
Conflicting utilities resolve by stylesheet order, not attribute
order. v4 dropped `cursor: pointer` on buttons; restore it.
