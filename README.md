# uber-front

Food delivery demo. The API is the `uber-eats` repo, on `http://localhost:4000/graphql`.

## Scripts

```bash
npm run dev
npm run build
npm start
npm run lint
npm run graphql:gen
```

## Env

`NEXT_PUBLIC_GRAPHQL_URL` — HTTP GraphQL endpoint. Defaults to `http://localhost:4000/graphql`.

`NEXT_PUBLIC_GRAPHQL_WS_URL` — WebSocket endpoint. Defaults to `ws://localhost:4000/graphql`.
